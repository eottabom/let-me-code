URL 인코딩 예제

파이프(|) 문자를 포함한 복합 필터를 백엔드로 전송합니다.
케이스 1·2는 기본 Tomcat 프로필, 케이스 3·4는 tomcat-relaxed 프로필로 서버를 실행하세요.

케이스 1 — FE 미인코딩 + 기본 Tomcat → 400

fetch에 |를 그대로 전달합니다 (encodeURIComponent 미사용).
Tomcat 이 RFC 7230 §3.2.6 위반으로 400 Bad Request를 반환합니다. 








  
케이스 2 — FE 인코딩 + 기본 Tomcat → 200

  

    encodeURIComponent로 |를 %7C로 변환 후 전송합니다.

    Tomcat 이 정상 디코딩하여 200 OK를 반환합니다.
  

  
  
  







  
케이스 3 — FE 미인코딩 + relaxed Tomcat → 200

  

    |를 그대로 전달하더라도, 서버가 relaxedQueryChars="|"로 설정되어 있으면

    200 OK를 반환합니다. 서버를 tomcat-relaxed 프로필로 실행하세요.
  

  
  
  







  
케이스 4 — FE 인코딩 + relaxed Tomcat → 200

  
인코딩 + relaxed 설정 모두 적용 시에도 정상 동작합니다.
