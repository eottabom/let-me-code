URL Encoding 예제

파이프(|) 문자를 포함한 복합 필터를 서버에 전송하는 네 가지 케이스를 직접 확인해보세요.

케이스 1: FE 미인코딩 + 기본 Tomcat 프로필 → 400

fetch에 |를 그대로 전달합니다. (encodeURIComponent 미사용)
기본 Tomcat 은 RFC 7230 §3.2.6 위반으로 400 Bad Request를 반환합니다. 

결과가 여기 표시됩니다.

케이스 2: FE 인코딩(encodeURIComponent) + 기본 Tomcat 프로필 → 200

encodeURIComponent로 |를 %7C로 변환 후 전송합니다.
Tomcat 이 정상적으로 디코딩하여 200 OK를 반환합니다. 

결과가 여기 표시됩니다.

케이스 3: FE 미인코딩 + tomcat-relaxed 프로필 → 200

|를 그대로 전달하지만, 서버가 relaxedQueryChars="|"로 설정되어 있으면
200 OK를 반환합니다. (서버를 --spring.profiles.active=tomcat-relaxed로 실행 필요) 

결과가 여기 표시됩니다.

케이스 4: FE 인코딩 + tomcat-relaxed 프로필 → 200

인코딩 + relaxed 설정 모두 적용 시에도 정상 동작합니다. 

결과가 여기 표시됩니다.
